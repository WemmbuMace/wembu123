# mc-ai-bot — ИИ-игрок для Minecraft, управляемый через чат

Бот заходит на твой сервер как обычный игрок (**ClaudeBot**) и выполняет команды,
которые ты пишешь в игровом чате: «иди ко мне», «вырубить дерево», «построй дом»,
«иди на 100 64 -20», «стоп». Думает и принимает решения модель **Claude Haiku**
(через Claude Agent SDK — это движок Claude Code, запущенный программно). Руки и
ноги бота — библиотека **mineflayer**.

Понимает команды на русском и английском и отвечает в чате на том же языке.

```
Ты (чат в Minecraft)  ─►  сервер MC (localhost:25565)
                                  ▲
                   mineflayer-бот "ClaudeBot"           ← ТЕЛО
                   pathfinder + collectblock + pvp
                                  ▲  (внутрипроцессные MCP-инструменты)
                   Claude Haiku (Agent SDK, streaming)  ← МОЗГ
                                  ▲
        цикл: чат-событие → понять команду → вызвать нужный навык → ответить
```

## Почему так, а не «мод» на Forge/Fabric

Ты просил ИИ-**игрока**, которым можно командовать. Отдельный игрок-компаньон
надёжнее всего делается через **mineflayer** (headless-клиент, заходит как второй
игрок), а не как мод внутри клиента. Это стандартный подход (так устроены mindcraft,
Voyager и др.), и он не требует модифицировать игру — работает с ванильным
Paper/Spigot/Fabric-сервером.

## Три уровня — почему результат предсказуем

Маленькой модели нельзя доверять вычисление координат каждого блока — она ошибается.
Поэтому:

1. **Примитивы** — атомарные надёжные действия (`goto`, `dig_block`, `place_block`,
   `find_blocks`, `say`, `get_status`, `list_inventory`).
2. **Навыки-макросы** — детерминированные процедуры, вся геометрия считается в коде
   (`come_to_player`, `follow_player`, `chop_tree`, `build_house`, `stop`).
3. **Мозг Haiku** — только понимает фразу, выбирает навык и параметры, отвечает в чат.

Модель решает **что и где**, код — **как**.

## Установка

### 1. Зависимости бота

```bash
cd mc-ai-bot
npm install
```
Нужен Node.js ≥ 20 (у тебя v24 — ок).

### 2. Minecraft-сервер (куда зайдут и ты, и бот)

Боту с обычным ником нужен сервер в **offline-режиме**.

- Поставь **Java 21** (для MC 1.21). Системная Java 8 не подойдёт —
  [Temurin 21](https://adoptium.net/temurin/releases/?version=21).
- Скачай [PaperMC 1.21.x](https://papermc.io/downloads/paper), положи в папку `server/`.
- Запусти `server/run-server.bat` один раз → появится `eula.txt` → поставь `eula=true`.
- В `server.properties` выставь **`online-mode=false`** (и желательно `gamemode=creative`
  для демо). Ориентир — `server/server.properties.sample`.
- Запусти сервер снова.

> ⚠️ «Open to LAN» из одиночной игры **не подойдёт** — там всегда online-режим и
> случайный порт, бот с обычным ником не зайдёт. Нужен отдельный сервер с
> `online-mode=false`.

> ⚠️ `online-mode=false` держи только в локальной сети — иначе зайти сможет кто угодно.

Ты сам заходишь на этот сервер обычным клиентом: **Multiplayer → Direct Connect →
`localhost`** (премиум-аккаунт спокойно заходит на offline-сервер).

### 3. Доступ к Claude (мозг)

Agent SDK берёт учётку от Claude Code. Если увидишь `OAuth session expired`, задай
API-ключ. В `.env`:

```
ANTHROPIC_API_KEY=sk-ant-...
```
Модель Haiku очень дешёвая. Как вариант — свежий вход `claude login` (если стоит
Claude Code CLI).

### 4. Конфиг

```bash
cp .env.example .env   # при желании отредактируй
```
Значения по умолчанию уже рассчитаны на `localhost:25565`, ник `ClaudeBot`, `auth=offline`.

### 5. Запуск

```bash
npm start
```
Зайди на сервер, убедись что `ClaudeBot` появился рядом, и пиши команды в чат.

## Команды (примеры)

| Ты пишешь в чат | Что делает бот | Навык |
|---|---|---|
| `иди ко мне` / `come here` | подходит к тебе | `come_to_player` |
| `следуй за мной` / `follow me` | идёт за тобой, пока не скажешь «стоп» | `follow_player` |
| `иди на 100 64 -20` | идёт к координатам | `goto` |
| `вырубить дерево` / `chop wood` | находит дерево, рубит, собирает брёвна | `chop_tree` |
| `построй дом` / `build a house` | строит домик 5×5×3 с дверным проёмом | `build_house` |
| `построй дом 7 на 7 из камня` | дом 7×7 из `stone` | `build_house` |
| `стоп` / `хватит` / `stop` | мгновенно всё останавливает | `stop` |
| `что у тебя в инвентаре?` | отвечает в чат | `list_inventory` |
| `где ты?` / `сколько хп?` | отвечает статус | `get_status` |

«стоп» обрабатывается мгновенно, без обращения к модели, — длинную задачу всегда
можно прервать.

Настройки чата в `.env`:
- `BOT_OWNER=Alex` — слушать только тебя (по умолчанию — любого игрока).
- `CHAT_PREFIX=бот ` — реагировать только на сообщения с этим префиксом.

## Как добавить новую команду

1. **Навык** в `src/skills.js` — обычная async-функция `(bot, state, ...args)`,
   возвращает строку-результат.
2. **Инструмент** в `src/tools.js` — `tool('имя', 'описание', { zod-схема }, handler)`.
3. Готово — Haiki сам подхватит инструмент по описанию. Системный промпт править не
   обязательно; для новых крупных навыков допиши подсказку в `SYSTEM_PROMPT`
   (`src/brain.js`).

## Структура

```
src/
  config.js   — конфиг из .env
  bot.js      — mineflayer-бот, плагины, состояние, авто-переподключение
  skills.js   — детерминированные навыки (вся «физика» здесь)
  tools.js    — навыки, обёрнутые как внутрипроцессные MCP-инструменты
  brain.js    — цикл Claude Agent SDK (streaming), модель Haiku, только MC-инструменты
  index.js    — точка входа: бот + мозг + чат + супервизор переподключения
server/       — образцы server.properties и bat-файла запуска сервера
test/
  brain-smoke.js — проверка мозга без Minecraft-сервера (нужен доступ к Claude)
```

## Диагностика

- **`OAuth session expired`** — задай `ANTHROPIC_API_KEY` в `.env` или сделай `claude login`.
- **`ECONNREFUSED`** — сервер не запущен / не на 25565. Бот сам переподключается каждые 5с.
- **Бот не заходит, кик по авторизации** — на сервере не выставлен `online-mode=false`.
- **`unsupported protocol version`** — версия сервера новее, чем знает mineflayer.
  Поставь сервер 1.21.11 или задай `MC_VERSION` под свою версию.
- **Не может строить/ломать у спавна** — `spawn-protection=0` или сделай бота оператором
  (`op ClaudeBot` в консоли сервера).
- **«build … skipped»** — не хватило материалов или блоку не на что опереться.
  Проще всего: сервер в `creative` (бот сам берёт блоки) или дай ему блоки/`op`.

## На чём построено (переиспользованные наработки)

- [mineflayer](https://github.com/PrismarineJS/mineflayer) + `-pathfinder`,
  `-collectblock`, `-pvp` — тело и навигация бота.
- [kolbytn/mindcraft](https://github.com/kolbytn/mindcraft) — паттерны навыков
  (GoalFollow для слежки, collectBlock для рубки, скан 6 граней при постройке,
  флаг прерывания для мгновенного «стоп»).
- [yuniko-software/minecraft-mcp-server](https://github.com/yuniko-software/minecraft-mcp-server)
  — референс набора инструментов (Apache-2.0).
- [Claude Agent SDK](https://code.claude.com/docs/en/agent-sdk/overview) — мозг (Haiku).
